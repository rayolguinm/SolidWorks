# SolidWorks Technical Portfolio

**Author:** Raymundo "R@y" Olguin · BE-221 Introduction to CAD · University of Arizona · Fall 2026
**Live site:** https://rayolguinm.github.io/SolidWorks/

## What this is
An interactive web portfolio of 58 SolidWorks parts, 9 assemblies and 18 ANSI drawings, with a
four-viewport 3D studio, engineering analysis typeset in LaTeX, and a phone layout for iPhone.

## Files
| Path | Purpose |
|---|---|
| `index.html` | The page (about 190 KB). Open Graph / Twitter tags in `<head>` give LinkedIn its preview. |
| `og-image.png` | 1200 x 627 share image that LinkedIn shows with the link. |
| `assets/` | 3D meshes (`.txt`, compressed), SolidWorks previews and drawing sheets (`.png`), renders (`.jpg`). |

## Publish on GitHub Pages
1. Delete the old `index` / `index.html` file in the repo.
2. **Add file > Upload files**, then drag in `index.html`, `og-image.png`, `README.md` **and the whole `assets` folder**. Commit.
3. Settings > Pages: Branch `main`, folder `/ (root)`.
4. After the green check, paste the site link into LinkedIn. If LinkedIn cached the old failure, refresh it at https://www.linkedin.com/post-inspector/
